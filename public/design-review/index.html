Charter at 840px: visual review

Captured in Chromium at desktop and mobile sizes. These screenshots show the selected typography prototype, with the comparison toolbar and explanatory footer hidden. The existing Next.js blog has not yet been restyled.

Return to the live typography comparison

What the screenshots show

  • Regular Charter titles and headings establish a clear hierarchy without the original semibold weight. The writing has the presence of a personal publication.
  • The 840px width feels open, but at 21px the opening paragraph has 81–93 characters on its full desktop lines. The 22px comparison is a useful final check for long-form comfort; the approved width stays fixed.
  • The mobile title scales well, including the four-line technical title. Mobile line spacing is now 1.55 (about 31px at a 390px viewport), with the same font size and margins. This tightens the reading rhythm while keeping the text comfortable.
  • Short inline code such as “200 OK” now stays together. Longer inline tokens can still wrap within the page, and code blocks scroll horizontally.
  • Navigation is understated. A small author name or home link labelled “Tony Oliverio” would give direct article arrivals a clearer sense of whose publication this is.
  • Dark mode preserves the reading hierarchy without stark white-on-black contrast.

Verified for the five main captures: Charter loaded, body weight 400, no JavaScript errors, and no horizontal page overflow. Full-page images are available below; all changes shown are in the prototype.
